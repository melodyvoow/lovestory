# LoveStory; (Google DeepMind AI Hackathon Track 1)

> **"Choose the moment of love. The story doesn’t end here."**

A cinematic interactive 9:16 short drama web application built for Google Cloud Run with single FastAPI backend + responsive frontend + local FFmpeg.

---

## 🌟 Key Features

1. **Dynamic Gender Casting (`cast_profile`)**: Select gender to lock visual identity (Mode A: Ijun / Mode B: Iseo).
2. **3-Cut Prequel Video Intro**: First Rain, Darkroom Promise, Rainy Cafe Entrance (skippable 9:16 vertical video roll).
3. **2-Turn Rainy Cafe Gameplay**: 3 inspectable clues (`wet_sleeve`, `postcard`, `itinerary`) + `gemini-4-argon` acting dialogue engine.
4. **THE WOW POINT — 3D Postcard Flip**: Interactive 3D CSS animation card flip revealing a personalized handwritten confession & P.S. note dynamically generated by `gemini-4-argon`.
5. **Systematic 5-Cut Short Drama Video Pipeline**:
   - `gemini-4-argon` (`thinking_level="high"`) 5-Cut continuity planner
   - Autonomous verification loop (JSON schema, cast profile, clue grounding, durations)
   - `gemini-nano-banana-2.1` 5-cut storyboard keyframes
   - Local FFmpeg instant `preview.mp4` compilation
   - `gemini-omni-1.1-flash` (`background=True`) short drama video clips
   - Local FFmpeg master concat with subtitles & rain audio into `master.mp4`
6. **Top-Right Judge Modal (`[🎬 Studio & Architecture]`)**: Interactive SVG architecture diagram & live continuity verification loop logs.

## 🚀 Quick Start (Local)

```bash
cd lovestory

# 1. Environment Variables (.env)
cp .env.example .env
# Edit .env and set GEMINI_API_KEY="AIza..."

# 2. Run with Python Virtualenv
source .venv/bin/activate
uvicorn main:app --host 0.0.0.0 --port 8080 --reload
```

Open `http://localhost:8080` in your browser.

## ☁️ Google Cloud Run Deployment

```bash
# Build and deploy directly to Cloud Run
gcloud run deploy lovestory \
  --source . \
  --platform managed \
  --region asia-northeast3 \
  --allow-unauthenticated \
  --max-instances 1 \
  --no-cpu-throttling \
  --memory 2Gi \
  --set-env-vars GEMINI_API_KEY="YOUR_API_KEY"
```
