Mandatory Video Formula · Motion

1970s Cinema Verite 필수 영상화 공식 (format_video_prompt)

gemini-omni-1.1-flash 비디오 생성 및 5컷 콘티 검증 루프에서 모든 video_motion_prompt가 반드시 준수해야 하는 공식입니다.

CINEMA_VERITE_SUFFIX = (
  "1970s cinema verite documentary style, candid street cinematography, "
  "authentic vintage broadcast look."
)

def format_video_prompt(scene_desc: str) -> str:
    cleaned = (scene_desc or "").strip().rstrip(".")
    if CINEMA_VERITE_SUFFIX.lower() in cleaned.lower():
        return cleaned if cleaned.endswith(".") else f"{cleaned}."
    return f"{cleaned}, {CINEMA_VERITE_SUFFIX}"
Cinematography Grammar · 3 Prequel + 5 Main Cuts

단조로움을 완전히 제거한 다채로운 카메라 앵글 문법

구분 필수 카메라 앵글 & 렌즈 문법 연출 의도 및 시각적 디테일
Prequel Cut 1 High-Angle Umbrella Two-Shot 투명 비닐우산 위에서 내려다본 하이앵글 투샷, 수채화 진주처럼 튀는 빗방울과 플레이어를 향한 시선
Prequel Cut 2 Extreme Macro Low-Angle Darkroom Shot 붉은 암실 안전등 아래 사진 엽서 뒷면 위에서 망설이는 황동 만년필 촉의 익스트림 매크로 로우앵글
Prequel Cut 3 Exterior-to-Interior Through-Glass Shot 비 내리는 창밖/플랫폼 안개 너머에서 실내의 두 사람을 바라보는 투과 익스테리어 샷
Main Cut 1 (4s) Exterior Through-Glass Wide/Medium Two-Shot 플레이어가 선택한 장소(카페/기차역/암실)의 공기감과 빗물 보케를 담는 도입부 투샷
Main Cut 2 (4s) 85mm Extreme Macro Shallow-DOF Insert 플레이어가 실제로 클릭한 단서(observed_clues)만을 85mm 극접사로 포착 (미클릭 단서 엄격 배제)
Main Cut 3 (6–8s) Intimate Over-the-Shoulder (OTS) / Dutch-Tilt Close-Up 결정적 대사와 흔들리는 눈빛을 포착하는 오버더숄더 및 감성 클로즈업
Main Cut 4 (5s) Dynamic Low-Angle Table-Level Action Close-Up 엔딩 타입별 결정적 행동(엽서를 건네며 맞닿는 손 / 두 손 위 약속 / 코트 주머니에 간직)
Main Cut 5 (4s) Top-Down Overhead Flat-Lay Transition 테이블 위 뒤집힌 사진 엽서 뒷면의 손글씨 본문과 P.S. 노트로 디졸브되는 탑다운 에필로그
Autonomous Verification Loop · _validate_five_cut_plan

gemini-4-argon (thinking_level="high") 5대 자율 검증 및 자기교정 규칙

1. [Rule 1: Schema & 5 Cuts] 정확히 5개의 컷(cut_number 1..5)과 각 컷의 duration_sec 범위(3~10초) 검증
2. [Rule 2: Cast Profile Consistency] 5개 모든 컷의 image_prompt에 성별 캐스팅(이준/이서) 시각 프롬프트 포함 강제
3. [Rule 3: Observed Clues Grounding] Cut 2에서 플레이어가 클릭하지 않은 단서(un-observed clue) 언급 시 즉시 차단 및 재작성
4. [Rule 4: 1970s Cinema Verite Formula] 모든 video_motion_prompt가 정확히 "1970s cinema verite documentary style, candid street cinematography, authentic vintage broadcast look."으로 끝나는지 검증
5. [Rule 5: Diverse Camera Angles] 5개 컷의 camera_angle이 중복 없이 서로 다른 5가지 시네마틱 앵글 문법을 사용하는지 검증
